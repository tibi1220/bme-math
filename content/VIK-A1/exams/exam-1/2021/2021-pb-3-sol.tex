\[
	a_n
	= \left(
	\frac{\left(1 - \frac{2}{n}\right)^n}{\left(1 + \frac{3}{n}\right)^n}
	\right)^5
	\to e^{-25}
\]
Mivel
\(
\left( \frac{n - 2}{3 + n} \right)^n \to e^{-5}
\),
ezért elég nagy $n$ esetén
\[
	0 < b_n
	= \left( \left( \frac{n - 2}{3 + n} \right)^n \right)^{n^4}
	< \left( e^{-5} + \varepsilon \right)^{n^4}
	\to 0,
\]
ha $0 < \varepsilon < 1 - e^{-5}$. Így $\lim b_n = 0$.
